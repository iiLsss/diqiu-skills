# Frontend Definition of Done

A change is complete when all applicable items are satisfied:

- Requested behavior is implemented without unrelated changes.
- Existing architecture, component, state, data, and styling conventions are followed.
- Accessibility and responsive behavior relevant to the change are verified.
- No unresolved type, lint, console, or build errors were introduced.
- Relevant tests cover business rules and critical interactions.
- No unapproved production dependency was added.
- Documentation and generated artifacts affected by the change are updated.
